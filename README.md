# 璀璨宝石：四人标准局

一个使用 `pygame` 制作的本地热座对战版璀璨宝石。四名玩家依次在同一台电脑上操作，采用标准四人局资源数量、三层发展卡、贵族、保留卡、黄金百搭宝石、10 枚宝石上限与终局规则。

## 启动

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

当前项目目录已准备好 `.venv` 时，直接执行最后一行即可。

## 操作

- 点击左侧彩色宝石选择：可拿 3 枚不同色，或在该颜色库存不少于 4 时双击同色拿 2 枚；然后点击“确认拿取”。
- 点击发展卡，再点击“购买所选”或“保留所选”。保留卡会获得 1 枚黄金（若库存仍有）。
- 购买后，符合条件的贵族会高亮，点击选择一位。
- 若宝石超过 10 枚，按提示点击左侧宝石归还。
- 有玩家达成 15 分后，本轮所有玩家完成行动，分数最高者获胜；同分时发展卡较少者获胜。
- 按 `R` 可随时开始新局。
